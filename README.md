# Чат-бот Student Helper

Навчальний проєкт чат-бота для допомоги студентам в організації навчання, пошуку літератури та роботі з навчальними матеріалами.

## Структура проєкту

- `main.py` — головний файл запуску застосунку.
- `src/` — основний вихідний код (`main.py`, `library.py`).
- `tests/` — тести проєкту (`test_pre_commit.py`).
- `books/` — база навчальної літератури (`books.json`).
- `config/` — файли конфігурації (`settings.json`).
